本节是对 MMCR 全部公共 API 的集中参考。教程文档中提到的所有 API 都可以在这里查到完整签名、参数约束、抛出条件与示例。

- [KubeJS](KubeJS) — 完整的 KubeJS 集成层 API 参考。

## 阅读建议

- 第一次阅读：仅看教程目录下 [JavaAPI/开始](/zh-cn/JavaAPI/BLAST_FURNACE) 与 [KubeJS/开始](/zh-cn/KubeJS/A_Simple_Machine) 两篇示例。
- 写代码时：按需跳转到本页对应文档查阅签名与边界条件。
- 写完代码后：回到教程页面，对照参考页检查是否触及注意事项一节列出的边界。
