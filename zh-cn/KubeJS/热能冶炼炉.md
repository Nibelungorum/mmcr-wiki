# 热能冶炼炉 — 等级系统

本文演示 MMCR 的 **Level 系统**：机器结构里有一个"等级槽位"，槽位上摆哪一块代表方块决定当前机器等级，不同等级叠加不同的配方修饰器。

## 机器简介

`热能冶炼炉` 由三个文件组成：

- `example/startup_scripts/A_Level_Machine.js`  

- `example/server_scripts/structure/A_Level_Machine.js`  

- `example/server_scripts/recipe/A_Level_Machine.js`  

Modifier 由结构上的方块动态决定。Level 由结构上**指定槽位**的方块决定，影响该机器能跑哪些配方。

## 机器定义

`startup_scripts/` 目录下的 [A_Level_Machine.js](https://github.com/Nibelungorum/ModularMachinery-Community-Refoxed/blob/f234477b/example/startup_scripts/A_Level_Machine.js)：

```js
// Use the level system and a shared structure.

MMCREvents.startup(event => {

    const api = event.getAPI()

    // Register the machine that uses levels.
    const builder = event
        .createMachine("mmcr_kubejs:kubejs_thermal_smelting_furnace")
        .displayNameKey("machine.mmcr_kubejs.kubejs_thermal_smelting_furnace")
        .recipePool("mmcr_kubejs:kubejs_thermal_smelting_furnace")
        .allowModifiers()
        .allowParallelism()
        .allowMultithreading()
        .maxParallelAmount(32)
        .appearance("minecraft:smooth_basalt")

    builder.register()

    // Register the level type before registering individual levels.
    event
        .createLevelType("mmcr_kubejs:thermal_smelting_coil")
        .displayNameKey('level.mmcr_kubejs.thermal_smelting_coil')
        .register()

    // Register three levels under that type.
    event.createLevel("mmcr_kubejs:thermal_smelting_coil_iron")
        .type("mmcr_kubejs:thermal_smelting_coil")
        .priority(0)
        .state('minecraft:iron_block')
        .modifier(api.modifierDefinition([
            api.modifier("duration", "input", 0.95, "multiply", false),
            api.modifier("energy", "input", 0.95, "multiply", false),
            api.modifier("parallelism", "machine", 4, "add", false)
        ]))
        .register()

    event.createLevel("mmcr_kubejs:thermal_smelting_coil_gold")
        .type("mmcr_kubejs:thermal_smelting_coil")
        .priority(1)
        .state('minecraft:gold_block')
        .modifier(api.modifierDefinition([
            api.modifier("duration", "input", 0.85, "multiply", false),
            api.modifier("energy", "input", 0.85, "multiply", false),
            api.modifier("parallelism", "machine", 6, "add", false)
        ]))
        .register()

    event.createLevel("mmcr_kubejs:thermal_smelting_coil_diamond")
        .type("mmcr_kubejs:thermal_smelting_coil")
        .priority(2)
        .state('minecraft:diamond_block')
        .modifier(api.modifierDefinition([
            api.modifier("duration", "input", 0.75, "multiply", false),
            api.modifier("energy", "input", 0.75, "multiply", false),
            api.modifier("parallelism", "machine", 6, "add", false)
        ]))
        .register()
})
```

### 机器定义本身没有 `.allowLevels(...)`

机器层没有"开启等级系统"的开关。在结构定义内使用 [`api.levelSlot(...)`](../API/KubeJS#kubejsapi)，自动启用该机器的等级系统。

`.allowMultithreading()` 允许工厂调度多个配方实例；`.allowParallelism()` 与 `.maxParallelAmount(long)` 控制每个实例的并行倍率及上限，不是线程数。等级的 `parallelism/machine` 修饰会参与并行能力计算。需要设置定义侧工厂线程上限时用 `.factoryThreads(int)`，本例未设置。

### 等级类型 `createLevelType(...)`

```js
event
    .createLevelType("mmcr_kubejs:thermal_smelting_coil")
    .displayNameKey('level.mmcr_kubejs.thermal_smelting_coil')
    .register()
```

等级类型（`LevelType`）是"等级分类"，代表一个可被升级的"维度"。比如本教程的"线圈"就是一个维度。

机器结构上有一个位置专门放线圈，铁 / 金 / 钻石线圈都属于这个维度。

链式：

- `.displayNameKey(...)`：本地化键。
- `.register()`：把等级类型提交到当前注册收集器。**必须在具体等级的 `.register()` 之前调用**；`.type(String)` 本身只记录 ID，不立即查询类型，真正的类型存在性检查在注册时执行。
详见 [API/KubeJS#leveltypebuilderjs](../API/KubeJS#leveltypebuilderjs) 的"注意事项"。

### 具体等级 `createLevel(...)`

```js
MMCREvents.startup(event => {
    const api = event.getAPI()
    event.createLevel("mmcr_kubejs:thermal_smelting_coil_iron")
        .type("mmcr_kubejs:thermal_smelting_coil")
        .priority(0)
        .state('minecraft:iron_block')
        .modifier(api.modifierDefinition([
            api.modifier("duration", "input", 0.95, "multiply", false),
            api.modifier("energy", "input", 0.95, "multiply", false),
            api.modifier("parallelism", "machine", 4, "add", false)
        ]))
        .register()
})
```

每个具体等级属于一个等级类型，由一个 `state` 方块标识，并自带一组修饰参数。链式：

- `.type(typeId)`：必填，指定父等级类型。
- `.priority(int)`：可选，等级顺序，默认 0，数值越大等级越高。同一类型的 priority 与代表状态都必须唯一，不能给三个等级都保留默认 0。
- `.state(Object)`：必填，代表该等级的方块。`Object` 可以是字符串（方块 ID，使用默认状态）或 `BlockState`。
- `.modifier(ModifierDefinition)`：可选，定义该等级带来的修饰符集合。通过 `api.modifierDefinition([...])` 创建。

`api.modifier(target, scope, value, operation, chance)` 创建数值修饰项。等级示例分别调整耗时、能耗和机器并行度。

铁 / 金 / 钻石线圈的 `ModifierDefinition` 分别将耗时和能耗乘以 `0.95` / `0.85` / `0.75`，并增加 `4` / `6` / `6` 点机器并行度。

等级修饰和结构上的动态修饰现在共用 `ModifierDefinition` 与 `MachineModifier` 模型；区别在于等级修饰由槽位方块决定，结构修饰由修饰器使用位决定。

### 启动期不可热加载

机器、等级类型、等级全部由启动期窗口统一管理。重启游戏才能生效。
详见 [API/KubeJS#mmcrstartupeventjs](../API/KubeJS#mmcrstartupeventjs)。

## 结构

`server_scripts/structure/` 目录下的 [A_Level_Machine.js](https://github.com/Nibelungorum/ModularMachinery-Community-Refoxed/blob/f234477b/example/server_scripts/structure/A_Level_Machine.js)：

```js
MMCREvents.server(event => {
    const api = event.getAPI()
    const structure = event.createStructure("mmcr_kubejs:kubejs_thermal_smelting_furnace")

    structure
        .pattern(['AAA','XXX','XXX','AAA'])
        .pattern(['AAA','X X','X X','ADA'])
        .pattern(['ABA','XXX','XXX','AAA'])
        .set('X', api.levelSlot("mmcr_kubejs:thermal_smelting_coil"))  // ← 等级槽位
        .set('A', api.anyOf(
            api.anyOfItemInput(),
            api.anyOfItemOutput(),
            api.anyOfEnergyInput(),
            api.parallelControllers(),
            api.factoryController(),
            api.block('minecraft:smooth_basalt')
        ))
        .set('D', api.block('minecraft:reinforced_deepslate'))
        .controller('B')
        .build()
})
```

### `api.levelSlot(typeId)` 把字符升级为等级槽位

```js
.set('X', api.levelSlot("mmcr_kubejs:thermal_smelting_coil"))
```

[`api.levelSlot(typeId)`](../API/KubeJS#kubejsapi) 返回 [`LevelSlot`](../API/KubeJS#kubejsapi)，匹配属于 typeId 等级类型的**任一 state 方块**。

与 `api.block(...)` 只匹配单一方块不同，槽位匹配的是"一组方块"，具体哪一组由所有 `MachineLevel.state(...)` 字段动态决定。

示例的 `X` 可以匹配铁块 / 金块 / 钻石块。

`X` 在本模式中有 16 个位置，属于同一个等级类型，不是一个孤立方块。成型解析要求同类型槽位使用同一等级，混搭铁 / 金 / 钻石线圈会产生等级不一致错误；等级修饰按解析出的等级应用，不按 16 个位置重复乘算。

## 配方

`server_scripts/recipe/` 目录下的 [A_Level_Machine.js](https://github.com/Nibelungorum/ModularMachinery-Community-Refoxed/blob/f234477b/example/server_scripts/recipe/A_Level_Machine.js)：

```js
ServerEvents.recipes( event => {
    // 铁线圈：10000 煤 + 8 生铁 = 9 铁锭
    event.custom({
        type: 'mmcr:machine_recipe',
        recipe_pool: 'mmcr_kubejs:kubejs_thermal_smelting_furnace',
        tick_time: 300,
        parallelized: true,
        requirements: [
            {
                type: 'mmcr:level',
                io: 'input',
                level_type: 'mmcr_kubejs:thermal_smelting_coil',
                level: 'mmcr_kubejs:thermal_smelting_coil_iron'
            },
            { type: 'minecraft:item', io: 'input',  item: 'minecraft:coal',     count: 10000 },
            { type: 'minecraft:item', io: 'input',  item: 'minecraft:raw_iron', count: 8 },
            { type: 'minecraft:item', io: 'output', stack: { id: 'minecraft:iron_ingot', count: 9 } },
            { type: 'neoforge:energy', io: 'input', fe_per_tick: 10 }
        ]
    })

    event.custom({
        type: 'mmcr:machine_recipe',
        recipe_pool: 'mmcr_kubejs:kubejs_thermal_smelting_furnace',
        tick_time: 300,
        parallelized: true,
        requirements: [
            { type: 'mmcr:level', io: 'input', level_type: 'mmcr_kubejs:thermal_smelting_coil', level: 'mmcr_kubejs:thermal_smelting_coil_gold' },
            { type: 'minecraft:item', io: 'input', item: 'minecraft:coal', count: 1 },
            { type: 'minecraft:item', io: 'input', item: 'minecraft:raw_gold', count: 8 },
            { type: 'minecraft:item', io: 'output', stack: { id: 'minecraft:gold_ingot', count: 9 } },
            { type: 'neoforge:energy', io: 'input', fe_per_tick: 12 }
        ]
    })
    event.custom({
        type: 'mmcr:machine_recipe',
        recipe_pool: 'mmcr_kubejs:kubejs_thermal_smelting_furnace',
        tick_time: 300,
        parallelized: true,
        max_threads: 4,
        requirements: [
            { type: 'mmcr:level', io: 'input', level_type: 'mmcr_kubejs:thermal_smelting_coil', level: 'mmcr_kubejs:thermal_smelting_coil_diamond' },
            { type: 'minecraft:item', io: 'input', item: 'minecraft:coal', count: 1 },
            { type: 'minecraft:item', io: 'input', item: 'minecraft:raw_copper', count: 8 },
            { type: 'minecraft:item', io: 'output', stack: { id: 'minecraft:copper_ingot', count: 9 } },
            { type: 'neoforge:energy', io: 'input', fe_per_tick: 10 }
        ]
    })
})
```

三条配方都在 `requirements` 中包含一条 `mmcr:level` 项，并分别使用不同等级 ID 与物品需求：

| 配方 | 最低等级 | 输入 | 输出 | 备注 |
| --- | --- | --- | --- | --- |
| 铁线圈 | `thermal_smelting_coil_iron` | 10000 煤 + 8 粗铁 | 9 铁锭 | 10 FE/tick |
| 金线圈 | `thermal_smelting_coil_gold` | 1 煤 + 8 粗金 | 9 金锭 | 12 FE/tick |
| 钻石线圈 | `thermal_smelting_coil_diamond` | 1 煤 + 8 粗铜 | 9 铜锭 | 10 FE/tick，`max_threads: 4` |

### `requirements` 中的 `mmcr:level` 项

```js
requirements: [
    {
        type: 'mmcr:level',
        io: 'input',
        level_type: 'mmcr_kubejs:thermal_smelting_coil',
        level: 'mmcr_kubejs:thermal_smelting_coil_iron'
    }
]
```

等级需求作为普通需求项放在 `requirements` 数组中；也可在 RecipeSchema 链式调用中使用 `.requiresLevel(typeId, levelId)`。

`mmcr:level` 项包含：

- `level_type`：等级类型 ID（与启动期 `createLevelType(...)` 一致）。
- `level`：具体等级 ID（与启动期 `createLevel(...)` 一致）。  
    等级必须属于指定类型，否则在配方注册阶段抛异常。  

语义是**同类型最低等级**：当前等级的 priority 至少达到所需等级，配方才会被选中。金线圈可以运行铁线圈配方，钻石线圈可以满足三条等级需求，不是指定等级 ID 的相等匹配。最终仍要满足物品、能量等其他需求。配方 `recipe_pool` 必须匹配机器声明的池。
编程式等价物是 [`MachineRecipeBuilderJS.requiresLevel(typeId, levelId)`](../API/KubeJS#machinerecipebuilderjs) 或 [`KubeJSApi.levelRequirement(typeId, levelId)`](../API/KubeJS#kubejsapi)，底层都会创建等级需求项。

### `max_threads` 字段

```js
max_threads: 4
```

数据驱动配方顶层字段，限制该配方最多占用几个工厂线程。

钻石线圈配方 `max_threads: 4` 给出该配方的线程上限，不保证实际同时运行 4 个实例；实际数量还受机器与工厂调度器容量约束。其他两条未写此字段，默认 1；0 表示不设配方侧线程上限。

详见 [API/KubeJS#machinerecipeschema](../API/KubeJS#machinerecipeschema)。

数据驱动配方支持热加载，修改后 `/reload` 即可。

## 特殊机制：Level 系统

### `MachineLevel.modifier` 与 `ModifierDefinition`

两个修饰器入口的区别：

| 系统 | 触发 | 作用时机 | 字段 |
| --- | --- | --- | --- |
| Modifier（合金炉） | 结构上指定位置的方块 | 配方运行时动态叠加 | `target` / `scope` / `value` / `operation` / `chance` |
| Level | 结构上等级槽位的方块 | 配方运行时叠加 | `ModifierDefinition` 中的 `MachineModifier` |

等级与结构修饰符使用相同的目标、作用域和操作格式。

等级由结构中的等级槽位决定，结构修饰符则由玩家在修饰器使用位放置的方块决定。
