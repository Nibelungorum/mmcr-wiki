# API Reference

This section is based on MMCR source commit [`f234477b`](https://github.com/Nibelungorum/ModularMachinery-Community-Refoxed/tree/f234477b) for Minecraft **26.1.2**. It documents the signatures, parameter constraints, execution semantics, and examples for the Java public API and KubeJS integration layer.

Java development uses **Java 25**, and the public API is located in `cn.howxu.mmcr.publicapi`. The KubeJS reference version is **26.1.2-8.0.6**. The script facade also returns underlying implementation objects, so the type names of the Java public interfaces cannot be applied directly.

## Documentation

- [JavaAPI](JavaAPI): Complete Java public API reference
- [KubeJS](KubeJS): Complete KubeJS integration-layer API reference
